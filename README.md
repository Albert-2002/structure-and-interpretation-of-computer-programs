# structure-and-interpretation-of-computer-programs

Structure and Interpretation of Computer Programs (SICP):

The book teaches foundational and universal principles of programming and software design.
This repository contains the code examples and exercises from the book. Entirely uses MIT Scheme, a dialect of the Scheme programming language.

_Moriturus te saluto._

**To run .scm files:**

```bash
mit-scheme --load "/path/to/file"
```
